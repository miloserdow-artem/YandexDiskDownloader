# Пошаговая инструкция для новичков (Как запустить скрипт с нуля)
Шаг 1. Установка Python
Скачайте и установите Python с официального сайта python.org.

Важно при установке: обязательно поставьте галочку внизу окна установки: Add Python to PATH (Добавить Python в переменные среды), иначе скрипт не запустится.

Шаг 2. Установка необходимых библиотек
Откройте командную строку на компьютере (в Windows нажмите комбинацию клавиш Win + R, введите cmd и нажмите Enter).

Установите библиотеку для работы с запросами и секретными файлами, выполнив команду:

Bash
pip install requests python-dotenv
Шаг 3. Как получить OAuth-токен от Яндекс Диска
Чтобы скрипт мог зайти в ваш аккаунт и скачать файлы, ему нужен специальный ключ (OAuth-токен). Получить его очень просто:

Перейдите на официальную страницу Яндекс OAuth: oauth.yandex.ru (если нужно — войдите в свой аккаунт Яндекс).

Нажмите кнопку «Зарегистрировать приложение» (или перейдите на страницу создания нового приложения).

Заполните форму:

Имя приложения: напишите любое (например, MyDiskDownloader).

В блоке «Платформы приложения» выберите «Веб-сервисы» (Web services).

В поле «Callback URI» укажите стандартную заглушку: [https://oauth.yandex.ru/verification_code](https://oauth.yandex.ru/verification_code)

Прокрутите страницу вниз и найдите пункт «Доступ к данным» (Scopes). В поисковой строке найдите или выберите галочками следующие разрешения (они нужны для чтения файлов):

cloud_api:disk.read (Просмотр файлов на Яндекс.Диске)

cloud_api:disk.app_folder (если файлы в папке приложения, но лучше выдать полный доступ или найти cloud_api:disk.write / чтение всего диска). Самый простой способ: найдите раздел «Яндекс Диск REST API» и отметьте галочками все пункты, связанные с чтением (Доступ к папке Яндекс.Диска, Чтение файлов).

Нажмите кнопку «Создать приложение» в самом низу.

После создания вы попадете на страницу приложения. Найдите параметр «ID приложения» (Client ID).

Чтобы получить сам токен, перейдите в браузере по ссылке (замените ВАШ_CLIENT_ID на скопированный ID приложения):
[https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID](https://oauth.yandex.ru/authorize?response_type=token&client_id=ВАШ_CLIENT_ID)

Яндекс спросит разрешения — нажмите «Войти» и «Разрешить».

Выведется страница с вашим OAuth-токеном (длинная строка из букв и цифр). Скопируйте его.

Шаг 4. Настройка папки со скриптом
Создайте на компьютере новую папку (например, YandexDownload).

Сохраните туда скрипт выше под именем downloader.py.

В этой же папке создайте текстовый файл и назовите его .env (обязательно с точкой впереди и без расширения .txt).

Откройте файл .env с помощью блокнота и вставьте туда ваш токен в таком виде:

Фрагмент кода
YANDEX_DISK_TOKEN=ваш_скопированный_токен_сюда
Сохраните файл.

Шаг 5. Настройка путей и запуск
Откройте файл downloader.py через любой текстовый редактор (например, Блокнот или VS Code).

В самом низу скрипта найдите строчки:

Python
DISK_PATH = "/название папки"
LOCAL_ROOT = r"D:\Жёсткий диск\Путь к папке куда будут скачиваться файлы"
Замените на ту папку на Яндекс Диске, которую хотите скачать (например, /Мои фото или оставьте / если качаете весь диск).

Замените путь в LOCAL_ROOT на папку на вашем компьютере, куда сохранить файлы.

Запустите командную строку в папке со скриптом (или перейдите в неё через cd путь_к_папке).

Запустите скрипт командой:

Фрагмент кода
python downloader.py
Примечание: Если какая-то часть файлов оборвется из-за интернета, просто запустите скрипт заново (python downloader.py). Он не станет скачивать всё сначала, а автоматически пропустит уже готовые файлы и докачает то, что не успел.
